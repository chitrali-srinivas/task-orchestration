1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
This product audit evaluates Survey Builder V1.1 (survey-builder-simplified)
across 35 quality dimensions, including functional correctness, end-to-end user
flows, UX heuristics (Nielsen 10), human-centered design (ISO 9241-210), visual
hierarchy, design-system consistency, responsive resilience (WCAG 2.2 Reflow),
accessibility (WCAG 2.2 Level A/AA), and data/schema integrity.

Summary of Audit Observations:
* Critical & High-Severity Areas:
  - Responsive / Mobile Viewports (< 768px): The main sidebar question hierarchy
    panel collapses (hidden md:flex) without a mobile drawer or question selector
    toggle, preventing users on tablet portrait and mobile screens from switching
    questions inside the visual builder.
  - Accessibility & Keyboard Traps: Custom list items, tree nodes, and drag handles
    lack explicit aria-selected, aria-expanded, and roving focus attributes,
    failing WCAG 2.1.1 (Keyboard) and WCAG 4.1.2 (Name, Role, Value).
  - Cascade Deletion Context: Deleting a parent question in the tree cascades or
    orphans child follow-ups without an upfront visual listing of affected
    descendant questions in the confirmation dialog.
  - Schema / Legacy Field Dual Maintenance: Schema export maintains both legacy
    fields (Parent_Dep, Opt_Dep, Qn_In) and normalized fields (parentQuestionId,
    followUpDepth), presenting data synchronization risks if JSON is edited
    out-of-band.
* Usability & Information Architecture:
  - The question configuration area separates parent follow-up context (top banner)
    from conditional trigger logic (under the Advanced tab), requiring mental
    stitching across disparate tabs.
  - Question picker algorithms and modal shells are duplicated across
    question-selector-modal.tsx, add-question-popover.tsx, and change-type-dialog.tsx.
* Design System & Visual Consistency:
  - Varied card padding (p-3.5 vs p-5), border radius tokens (rounded-lg vs rounded-xl),
    and button height scales (h-7, h-8, h-9) exist across editor tabs and toolbars.
* Version Isolation:
  - V1.1 state, schema normalizers, serializers, diff engines, and localStorage
    persistence are fully decoupled from V1.0 under scoped keys (simplified_*),
    confirming that V1.0 remains insulated.

4. DETAILED FINDINGS
--------------------------------------------------------------------------------

[FUNC-001] P2 (Major) - Response Options Bulk Edit Resets Scores
Location: src/app/layouts/survey-builder-simplified/components/editor/tabs/options-tab.tsx
Reproduction: Edit existing scored options via "Bulk Edit" textarea and apply changes.
Actual: Entire option array is recreated with default score = 0, discarding scores.
Impact: Silent data loss during bulk editing of weighted question choices.
Fix Recommendation: Perform key/index reconciliation during bulk parse to retain scores.

[UX-001] P2 (Major) - Disconnected Parent Trigger Context & Visibility Logic
Location: src/app/layouts/survey-builder-simplified/components/editor/tabs/logic-tab.tsx
Reproduction: Open a follow-up question; examine Logic tab.
Actual: Parent trigger condition is rendered in top banner; Logic tab displays rules
without showing the inherited parent condition.
Impact: Authors cannot verify compound rule behavior (Parent Trigger AND Custom Rules).
Fix Recommendation: Display read-only Parent Trigger Card above custom rules in Logic tab.

[UX-002] P2 (Major) - Delete Modal Lacks Descendant Question Preview
Location: src/app/layouts/survey-builder-simplified/components/question-list/delete-question-dialog.tsx
Reproduction: Delete a parent question with 3 nested follow-ups.
Actual: Modal states "Will delete 3 follow-up questions" without listing question names/IDs.
Impact: Risk of accidental loss of descendant sub-question schemas.
Fix Recommendation: Render expandable tree list of all descendant questions in modal.

[UX-003] P3 (Minor) - Master Dataset Options Cannot Be Previewed in Editor
Location: src/app/layouts/survey-builder-simplified/components/editor/tabs/options-tab.tsx
Reproduction: Select "Selected Dropdown" type with master dataset.
Actual: Only dataset name and badge are shown without sample record browser.
Impact: Authors must enter preview runtime to verify cascading options.
Fix Recommendation: Add collapsible "View Sample Records" popover in Options tab.

[UI-001] P3 (Minor) - Inconsistent Card Padding & Border Radius Tokens
Location: src/app/layouts/survey-builder-simplified/components/editor/tabs/basic-settings-tab.tsx
Reproduction: Compare Question Details card (p-5, rounded-xl) with Unit card (p-3.5, rounded-lg).
Impact: Visual fragmentation in nested form containers.
Fix Recommendation: Standardize card tokens to p-4/rounded-xl and nested groups to p-3.5/rounded-lg.

[UI-002] P3 (Minor) - Step 2 Question Creation Modal Vertical Asymmetry
Location: src/app/layouts/survey-builder-simplified/components/common/question-selector-modal.tsx
Reproduction: Select Subjective type; advance to Step 2.
Actual: Left column contains only 2 fields, leaving 240px empty space above footer.
Impact: Asymmetrical density against right preview card.
Fix Recommendation: Rebalance row density and align column items to top.

[UI-003] P4 (Polish) - Long Title Wrap Misaligns Tree Node Badges
Location: src/app/layouts/survey-builder-simplified/components/question-list/question-list-item.tsx
Reproduction: Enter 3-line question title in editor; inspect tree node.
Actual: Action buttons stretch vertically when inner container is unclamped.
Fix Recommendation: Apply flex-shrink-0 to badge container and line-clamp-2 to title.

[RESP-001] P1 (Critical) - Question List Hidden on < 768px Viewports Without Drawer
Location: src/app/layouts/survey-builder-simplified/page.tsx
Reproduction: View Builder at 768px or 390px viewport width.
Actual: Question List panel has class "hidden md:flex" with no mobile drawer trigger.
Impact: Tablet portrait and mobile users cannot switch active questions in editor.
Fix Recommendation: Implement mobile Sheet trigger in header for < md viewports.

[RESP-002] P2 (Major) - Question Creation Modal Horizontal Overflow at 390px
Location: src/app/layouts/survey-builder-simplified/components/common/question-selector-modal.tsx
Reproduction: Open Add Question modal at 390px mobile viewport.
Actual: Modal fixed min-width (720px) overflows screen; action buttons clipped.
Impact: WCAG 2.2 1.4.10 (Reflow) failure.
Fix Recommendation: Add responsive class overrides: max-w-[95vw] md:max-w-4xl p-4.

[A11Y-001] P1 (Critical) - Question Tree Missing ARIA Tree Roles & Keyboard Nav
Location: src/app/layouts/survey-builder-simplified/components/question-list/question-list-item.tsx
Reproduction: Navigate question tree using Tab and Arrow keys.
Actual: Renders plain <div onClick> without role="treeitem", aria-selected, or roving focus.
Impact: WCAG 2.1.1 (Keyboard) and 4.1.2 (Name, Role, Value) failure.
Fix Recommendation: Add role="treeitem", aria-selected, and ArrowUp/Down key navigation.

[A11Y-002] P2 (Major) - Icon-Only Toolbar Buttons Missing Accessible Names
Location: src/app/layouts/survey-builder-simplified/components/header/survey-header.tsx
Reproduction: Inspect inline action buttons with screen reader.
Actual: Action buttons contain SVG icons without aria-label or title.
Impact: WCAG 4.1.2 failure.
Fix Recommendation: Add descriptive aria-label attributes to all icon buttons.

[A11Y-003] P2 (Major) - Muted Helper Text Fails WCAG AA Contrast Ratio
Location: src/app/layouts/survey-builder-simplified/components/editor/tabs/
Reproduction: Evaluate text-zinc-400 (#a1a1aa) against white background.
Actual: Contrast ratio is 3.01:1 (WCAG AA requires 4.5:1).
Impact: WCAG 1.4.3 (Contrast Minimum) failure.
Fix Recommendation: Upgrade muted helper text tokens from text-zinc-400 to text-zinc-500/600.

[DS-001] P2 (Major) - Duplicate Question Type Picker Implementations
Location: question-selector-modal.tsx, add-question-popover.tsx, change-type-dialog.tsx
Current State: 3 separate picker implementations with divergent search and category logic.
Impact: Inconsistent categorizations, maintenance divergence.
Fix Recommendation: Extract a shared <QuestionTypeGrid /> component.

[DS-002] P3 (Minor) - Inconsistent Button Sizing Scale Across Views
Location: survey-header.tsx vs survey-table-view.tsx
Current State: Header uses h-8; Table uses h-9; Editor tabs use h-7.
Fix Recommendation: Standardize action buttons to Shadcn size tokens (size="sm" / size="default").

[VAL-001] P2 (Major) - Number Min/Max Inversion Lacks Immediate Inline Error
Location: src/app/layouts/survey-builder-simplified/components/editor/tabs/validation-tab.tsx
Reproduction: Set Min = 100, Max = 50 on Number question.
Actual: Inputs accept values without inline error state until global validator runs.
Impact: Authors can save invalid number ranges.
Fix Recommendation: Add immediate cross-field validation highlighting inputs when Max < Min.

[VAL-002] P3 (Minor) - Regex Tester Evaluates Empty Pattern as Valid Match
Location: src/app/layouts/survey-builder-simplified/components/editor/tabs/regex-help-popover.tsx
Reproduction: Leave regex pattern blank; type test string.
Actual: Shows green "Pattern matches" badge.
Fix Recommendation: Set idle status when pattern is empty.

[I18N-001] P2 (Major) - Custom Validation Error Messages Omitted From Translation Tab
Location: src/app/layouts/survey-builder-simplified/components/editor/tabs/translation-tab.tsx
Reproduction: Add custom error message; open Translations tab.
Actual: Only Title, Description, and Options are exposed for translation.
Impact: Multi-lingual surveys show English error messages to non-English respondents.
Fix Recommendation: Expose customErrorMessage in translation field mapper.

[I18N-002] P3 (Minor) - RTL Text Alignment & Radio Mirroring in Preview
Location: src/app/layouts/survey-builder-simplified/components/preview/preview-runtime.tsx
Reproduction: Preview survey in Arabic (ar).
Actual: Text renders right-to-left within left-aligned containers; radios remain on left.
Fix Recommendation: Inject dir="rtl" on preview container and use logical margin classes.

[SCHEMA-001] P2 (Major) - Serializer Maintains Dual Legacy & Normalized Hierarchy Fields
Location: src/app/layouts/survey-builder-simplified/lib/survey-serializer.ts
Reproduction: Export JSON.
Actual: Emits both normalized (parentQuestionId) and legacy (Parent_Dep, Opt_Dep) keys.
Impact: Schema ambiguity and potential synchronization divergence.
Fix Recommendation: Separate canonical serialization from legacy export adapters.

[VERSION-001] P3 (Minor) - Rapid Auto-Saves Generate Micro-Versions
Location: src/app/layouts/survey-builder-simplified/services/survey-service.ts
Reproduction: Type rapidly in Question Editor; inspect Version History.
Actual: Fast saves generate duplicate micro-versions.
Fix Recommendation: Implement semantic diff filter in version-diff-engine.ts.

[AUDIT-001] P3 (Minor) - Change Log Outputs Generic Array Diffs for Options
Location: src/app/layouts/survey-builder-simplified/lib/version-diff-engine.ts
Reproduction: Rename an option label; inspect Change Log.
Actual: Displays "Field 'options' modified (3 items -> 3 items)".
Fix Recommendation: Add option-level item diffing in version-diff-engine.ts.

[PERF-001] P3 (Minor) - Question Tree Re-renders on Every Editor Keystroke
Location: src/app/layouts/survey-builder-simplified/components/question-list/question-list-item.tsx
Reproduction: Edit title in large survey (40+ questions).
Actual: All 40 tree items re-render on every keystroke.
Fix Recommendation: Wrap QuestionListItem in React.memo with prop comparison.

[COPY-001] P4 (Polish) - Inconsistent "Mandatory" vs "Required" Terminology
Location: question-selector-modal.tsx vs basic-settings-tab.tsx
Reproduction: Modal uses "Mandatory Response"; Editor uses "Required Question".
Fix Recommendation: Standardize terminology to "Required" across all surfaces.
